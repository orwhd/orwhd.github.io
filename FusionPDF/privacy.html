Privacy Policy for FusionPDF

This Privacy Policy explains how the FusionPDF Chrome extension and FusionPDF Desktop Companion handle user data.

Effective September 22, 2026 Chrome extension + Desktop Companion
01 / LOCAL PDF processing stays on your computer

The Desktop Companion processes selected PDFs locally and communicates with the extension through a loopback connection.

02 / PROVIDER You choose the translation provider

FusionPDF sends translation requests only to the OpenAI-compatible provider you configure.

03 / CONTROL API key memory is optional

Keys remain in memory by default and are saved only when you explicitly enable Remember.

04 / TRUST Your data is not sold

FusionPDF does not sell user data or share it with advertisers or data brokers.

FusionPDF consists of the FusionPDF Chrome extension and FusionPDF Desktop Companion, a locally installed backend manager. The Chrome extension and Desktop Companion are distributed separately.

01

Scope

This policy applies to:

  • The FusionPDF Chrome extension
  • The FusionPDF Desktop Companion
  • The FusionPDF welcome, download, and documentation pages

It does not apply to third-party services selected by the user, including OpenAI-compatible translation providers.

02

Data FusionPDF processes

FusionPDF processes data only when the user explicitly opens or selects a PDF through the extension. The following data may be processed:

  • PDF files selected by the user
  • PDF pages and page images
  • Text-region crops generated from PDF pages
  • Target translation language
  • Source language when provided
  • Provider URL
  • Provider model identifier
  • Provider API key
  • Translation preferences, including font size and reasoning settings
  • Non-sensitive model capability information
  • Temporary document session identifiers
03

How data is used

FusionPDF uses this data only to:

  • Open and display user-selected PDFs
  • Locate text regions in PDF pages
  • Prepare page or text-region images for translation
  • Send translation requests to the provider configured by the user
  • Display translation results in the Chrome extension
  • Remember user settings and optional preferences
  • Maintain local document sessions until they expire or are removed

FusionPDF does not use user data for advertising, profiling, creditworthiness, lending, or purposes unrelated to the extension's single purpose.

04

Local processing

PDF processing and layout detection are performed by FusionPDF Desktop Companion on the user's own computer. The Desktop Companion is designed to run locally and listen on the loopback address:

127.0.0.1:53127

PDF files and temporary document sessions are stored locally by the Desktop Companion for processing and are designed to expire automatically. By default, document sessions expire after approximately 30 minutes of inactivity. Users can also remove the Desktop Companion and its local application data.

05

External translation providers

FusionPDF does not include a built-in translation provider or API key. When the user requests a translation, FusionPDF sends the relevant text-region images and translation request to the external OpenAI-compatible provider configured by the user.

The provider may receive

  • Text-region images generated from the PDF
  • Translation instructions
  • Target language
  • Source language when provided
  • Provider model identifier
  • Authentication credentials required by that provider

The provider's own privacy policy and data-retention practices apply to data it receives. Review the provider's terms before using it.

06

Data storage

The Chrome extension may store the following data in extension storage:

  • Provider URL
  • Provider model
  • Translation font size
  • Reasoning and thinking-effort preferences
  • Non-sensitive model capability summaries

The API key is kept in memory by default.

The API key is written to chrome.storage.local only when the user explicitly enables the Remember option. The extension does not store API keys in ordinary website localStorage.

07

Data sharing

  • FusionPDF does not sell user data.
  • FusionPDF does not share user data with advertisers or data brokers.
  • FusionPDF transfers PDF-derived translation data only to the external provider selected by the user for the requested translation.
  • FusionPDF does not transfer user PDF content to a FusionPDF-operated cloud service in the current release.
08

Data retention

  • Extension settings remain until the user changes them, clears extension data, or uninstalls the extension.
  • A remembered API key remains in chrome.storage.local until the user disables Remember, clears extension storage, or uninstalls the extension.
  • Desktop Companion document sessions are temporary. They expire after approximately 30 minutes of inactivity by default and are normally removed shortly afterward.
  • Local model caches remain until removed by the user or by the Desktop Companion upgrade or uninstall process.
  • Data retained by an external provider is controlled by that provider, not by FusionPDF.
09

Security

FusionPDF uses the following safeguards:

  • The extension communicates with the local backend through a loopback address.
  • The extension does not request access to arbitrary websites.
  • The extension does not read browsing history, bookmarks, cookies, or unrelated browser data.
  • Logs are designed not to record API keys, authorization values, or complete user documents.
  • The browser extension does not execute remotely hosted code.

Users should use a trusted external provider and, where possible, an HTTPS provider endpoint.

10

Chrome permissions

FusionPDF requests only permissions needed for its single purpose:

  • storage: saves provider configuration, user preferences, non-sensitive capability summaries, and an optional remembered API key.
  • contextMenus: adds the Open FusionPDF action to the extension action menu.
  • http://127.0.0.1:53127/*: communicates with the locally installed Desktop Companion.

FusionPDF does not request <all_urls>, browsing-history, tab-content, download-management, or native-messaging permissions.

11

User choices and deletion

Users can:

  • Disable Remember to stop storing the API key
  • Clear extension storage
  • Uninstall the Chrome extension
  • Stop or uninstall FusionPDF Desktop Companion
  • Delete local Desktop Companion data and model caches
  • Delete or rotate provider credentials through the provider's website
  • Delete data retained by the provider according to that provider's policy
12

Children

FusionPDF is not directed to children under the age of 13. FusionPDF does not knowingly collect personal information from children.

13

Changes to this policy

This Privacy Policy may be updated when FusionPDF changes its data practices or features. The updated policy will include a new effective date and will be published at the privacy policy URL listed in the Chrome Web Store.

15

Chrome Web Store Limited Use

FusionPDF uses user data only to provide its disclosed single purpose: processing user-selected PDFs, locating text regions through the locally installed Desktop Companion, and displaying translations from the provider configured by the user.

FusionPDF does not:

  • Sell user data
  • Transfer user data for advertising
  • Use user data to determine creditworthiness or eligibility for lending
  • Use or transfer user data for purposes unrelated to its single purpose
